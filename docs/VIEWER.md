# SR4D 인터랙티브 4D 뷰어 (A안: viser + nerfview)

브라우저에서 마우스로 카메라를 돌리며 시간 슬라이더로 4D 결과를 봅니다. 서버에서 렌더하고 이미지를 스트리밍합니다.

## 실행 (서버)

```bash
cd /data/AI-Graphics/Applications/SR4D
conda activate sr4d
# 학습 중인 GPU를 피해서 빈 GPU를 지정 (nvidia-smi로 확인; SR4D 학습 1개 ≈ 17 GB)
CUDA_VISIBLE_DEVICES=<빈 GPU> PYTHONPATH=. python tools/viewer4d.py --host 0.0.0.0 --port 8080 --datasets zju dance
```

## 접속 (내 컴퓨터)

같은 연구실 네트워크: 브라우저에서 `http://192.168.0.31:8080` (서버 IP는 `hostname -I`로 확인).
네트워크 밖이면 SSH 터널:

```bash
ssh -L 8080:localhost:8080 <사용자>@<서버>
# 브라우저에서 http://localhost:8080
```

## 화면 (v2, 2026-10-13 — nerfview 없이 viser 직접; v1은 tools/viewer4d_nerfview_v1.py)

- **마우스**: 왼쪽 드래그 = 사람(현재 프레임 골반) 중심 회전, 오른쪽 드래그 = 상하·좌우 이동, 휠 = 확대. 세계 위쪽 = +y.
- **4D**: 데이터, 방법(SR4D / DualGS / 4DGS / SR4D | DualGS 나란히 — 같은 카메라·같은 프레임), 시간, 재생·fps, 배경, 최대 해상도.
  재생 중에도 매 프레임을 멈췄을 때와 같은 해상도·JPEG 90으로 그림. 렌더가 fps를 못 따라가면 프레임을 건너뜀(화질은 낮추지 않음).
- **카메라**: 생성 카메라 48대 중 하나로 이동(목록 또는 frustum 클릭; 주황 = 학습, 파랑 = ho8 홀드아웃).
  **궤도 모드**: 구 / 원기둥 면 위로만 이동(중심 = 전 프레임 평균 골반, 반지름 = 카메라 평균 거리; 원기둥은 수평 반지름이 카메라와 일치),
  항상 중심을 바라봄, 초점거리는 가까운 카메라 2대에서 보간. ◀▶ = 방위각, ▲▼ = 고도(원기둥은 높이), 스텝 1°/5°, 슬라이더로 직접 입력,
  드래그해도 면 위로 다시 붙음. 방위각 360°, 고도 −30°~+80°(원기둥 높이 −0.8~+2.5 m)까지 외삽.
  화면에 방위각·고도, 가장 가까운 학습 카메라와의 각도, 보간/외삽 표시. 모드를 끄면 그 시점에서 자유 이동.
- **사람 회전**: yaw/pitch/roll(골반 중심) 숫자 입력·버튼(±5°)·원래대로. 궤도 모드에서는 원래대로 돌리고 잠금.
  (사람을 돌리는 것과 같은 결과가 되도록 카메라를 반대로 움직여 렌더 — SH 색까지 정확)
- **SR4D 진단용**: L2 Δx, L3 렌더 시 끄기.
- SR4D는 `outputs/sr4d_final/<run>_cam0`가 있으면 그것(cam0 기준선), 없으면 기존 모델을 씀 — 상태줄에 표시.
- 제약: viser는 키보드 이벤트를 서버에 전달하지 않아 방향키·Q/E는 지원 못 함 → 패널의 ◀▶▲▼·회전 버튼으로 대체.
